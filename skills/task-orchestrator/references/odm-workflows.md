# Nutrition ODM/CDMO workflows

Read this reference when the task concerns nutrition-product ODM/CDMO marketing, business development, contact mapping, or a brand customer pool. Select only requested stages. This is a routing map, not an instruction to run every stage or to install every candidate skill.

## Shared evidence rules

- Define geography, product category, channel, buyer type, and the user's manufacturing capabilities when material. Keep the user's own account-grading criteria if provided.
- Distinguish **brand**, legal entity, distributor, and manufacturer; do not merge them merely because names or owners resemble each other.
- Record source URL, observation date, product or company entity, and confidence for consequential claims. Separate observed facts from estimates and hypotheses.
- When a current partner or active account exclusion list is available, check candidates against it before presenting new leads. An absent name match alone does not prove there is no relationship; flag unresolved parent, subsidiary, or brand relationships.
- Avoid treating public shelf price, review count, follower count, or total GitHub Stars as verified revenue, market share, demand, or skill quality.

## Proposal checks that often change the decision

Before recommending an ingredient, claim, format, or commercial proposal, route to current target-market rules and authoritative evidence for regulatory/claims review, and to available manufacturing information for formulation, stability, packaging, MOQ, and cost feasibility. If evidence is missing, label the recommendation provisional and list the specific verification needed. No external nutrition-specific skill has been validated for these checks here.

External links above identify candidate instructions reviewed for routing. They are not installed by this reference, and their availability may change. Read an external skill's current instructions and dependencies before use; use the host's available tools and higher-priority instructions when they differ.
